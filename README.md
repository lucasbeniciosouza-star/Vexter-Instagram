# vexter-instagram

Repositório público de publicação do @somosvexter. Contém somente o que será publicado.

Estrutura: publicacoes/AAAA-MM-DD/ com manifest.json, carrossel/ (terça, quinta e sexta) e stories/ (segunda a sexta).
Imagens em JPEG (.jpg): slides 1080 x 1350, Stories 1080 x 1920. Sem Reels por enquanto.
Chave geral: um arquivo PAUSAR.txt na raiz suspende toda publicação.
